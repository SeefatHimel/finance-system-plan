# Project Q&A

This folder is an interview preparation guide for the finance system. It is
written to help explain the project clearly: what it does, why decisions were
made, how the architecture works, and what tradeoffs remain.

## How To Use This

- Read the global questions first.
- Practice answering out loud in your own words.
- Use the project-specific files when the interviewer goes deeper.
- Keep answers honest: mention what is implemented, what is planned, and why.
- Avoid pretending the project is finished. A clear roadmap is stronger than a
  vague claim.

## Current Project Status

- Product plan and architecture are documented.
- Django backend has health, JWT auth, accounts, categories, transactions, and
  monthly report foundations.
- Next.js web app has an initial dashboard shell and backend health check.
- PostgreSQL local infrastructure is documented through Docker Compose.
- Mobile app is planned but not scaffolded yet.
